# Saransh.dev — Portfolio Website

A modern, responsive portfolio site for Saransh Maurya — AIML student & full-stack developer.

🔗 Live: https://buildwithsaransh.github.io

## Built With

- HTML5, Tailwind CSS (PostCSS build)
- Vanilla JavaScript
- Google Fonts — Space Grotesk, Inter, JetBrains Mono

## Sections

- Hero — intro & socials
- About
- Education
- Skills
- Projects
- Experience & Achievements
- Contact

## Run Locally

```bash
git clone https://github.com/BuildWithSaransh/BuildWithSaransh.github.io.git
cd BuildWithSaransh.github.io
npm install
npm run build
npx serve .
```

## Deployment

GitHub Pages serves the static files from the repository; it does not run the CSS build. Before deploying, generate `css/output.css` and commit it:

```bash
npm install
npm run build
git add css/output.css
git commit -m "Build CSS for GitHub Pages"
git push origin main
```

In the repository settings, go to **Pages** and select **Deploy from a branch**, with `main` and `/(root)` as the source. GitHub Pages will publish the site at https://buildwithsaransh.github.io.
