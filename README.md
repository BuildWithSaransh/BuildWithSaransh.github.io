# Saransh.dev — Portfolio Website

A modern, responsive portfolio site for Saransh Maurya — AIML student & full-stack developer.

🔗 Live: https://buildwithsaransh.github.io

## Built With

- HTML5, Tailwind CSS (PostCSS build)
- Vanilla JavaScript
- Google Fonts — Space Grotesk, Inter, JetBrains Mono

## Sections

- Hero — intro & socials
- About
- Education
- Skills
- Projects
- Experience & Achievements
- Contact

## Project Structure

```
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── asset/
    └── image.jpeg
```

## Run Locally

```bash
git clone https://github.com/BuildWithSaransh/BuildWithSaransh.github.io.git
cd BuildWithSaransh.github.io
open index.html   # or use a local server, e.g. `npx serve`
```

## Deployment

Hosted via GitHub Pages, auto-deployed from the `main` branch.
